# Electric_Vehicle_Data_Analysis
Electric Vehicle Data Analysis using SQL and Python (NumPy, Pandas, Matplotlib, Seaborn).
SQL Tasks Performed:
Retrieve total EV registrations by state
Identify top manufacturers
Find average electric range by vehicle type
Use JOINs to combine manufacturer and location data
Use Subqueries to find vehicles above average range
Use Window Functions to rank top states by EV adoption
Calculate KPIs such as:
% of EVs by manufacturer
Average range trend over years

Python Tasks Performed (in Google Colab):
Import dataset and clean missing values using Pandas
Compute descriptive statistics using NumPy
Visualize trends:
EV adoption by year (Matplotlib)
Top 10 manufacturers (Seaborn bar chart)
Correlation between range and price (Seaborn heatmap)
